# R2-009 Changelog

## Gate

R2-009 — Activity Time Filter

## Updated

- Replaced ActivityTimeFilter placeholder with a visual filter
- Added Today, Week, and Month filter options
- Set Today as the selected visual state
- Added inactive states for Week and Month
- Added rounded container styling
- Added horizontal scroll safety to avoid overflow

## Purpose

This gate adds the visual time filter required for the Activity page.

## Behavior

In this release, the filter is visual only.

Today is selected by default.

Week and Month are inactive placeholders for future behavior.

## Notes

No real time-filtering logic was implemented in this gate.
