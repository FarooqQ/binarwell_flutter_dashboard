# R2-021 — Version Delta Documentation

## Gate

R2-021 — Release Baseline Protection & Version Delta Documentation

## Compared Versions

| Version | Meaning |
|---|---|
| v1.0.0 | First public baseline release |
| v1.1.0 | Release 2 Activity-first multi-page expansion |

## What v1.0.0 Represents

Version v1.0.0 represents the first public version of the CarePulse Flutter Dashboard.

It focuses on:

- Wellness overview dashboard
- Sidebar layout
- Dashboard cards
- Mock data
- Clean Flutter UI structure
- Portfolio-ready dashboard presentation

## What v1.1.0 Adds

Version v1.1.0 adds Release 2 improvements:

- Navigation model and page identity
- Sidebar active state
- DashboardShell page switching
- Placeholder pages for future expansion
- Activity feature architecture
- Activity models
- Activity mock data
- Activity page layout
- Today / Week / Month filter
- Today's Movement card
- Activity Goals card
- Hourly Movement chart card
- Today's Activity Sessions card
- Intensity Zones card
- Activity Insights card
- Visual consistency review
- Responsive review
- Activity widget test coverage
- Release 2 documentation package
- README and screenshots preparation

## What v1.1.0 Does Not Add

Release 2 does not add:

- Backend integration
- Authentication
- Real database persistence
- Real wearable device connection
- Real report export
- Real time-filter logic
- Production health-data processing

## Public Positioning

v1.0.0 should be presented as:

First public polished dashboard prototype.

v1.1.0 should be presented as:

Activity-first multi-page expansion built on top of the original dashboard.

## Release Strategy

The correct release strategy is:

- Keep v1.0.0 as the original public release
- Commit Release 2 changes separately
- Tag Release 2 as v1.1.0
- Publish v1.1.0 as a new GitHub release
- Explain the difference between v1.0.0 and v1.1.0 in the release notes

## Decision

The version delta between v1.0.0 and v1.1.0 is documented and ready for final release review.
