# BinarWell Flutter Dashboard v1.1.0 Scope

## Release Name

Release 2 � Activity-First Multi-Page Expansion

## Version

v1.1.0

## Main Goal

The goal of Release 2 is to expand BinarWell Flutter Dashboard from a single-page wellness dashboard into a multi-page front-end dashboard system, starting with a dedicated Activity page.

## Primary Page in This Release

Activity Page

## Visual Reference

The Activity page must follow the uploaded visual reference:

Refererence_Activity_Page

## Main Scope

Release 2 will include:

- Interactive sidebar navigation
- DashboardShell page switching
- Dedicated Activity page
- Activity-specific visual layout
- Placeholder pages for future modules
- Release 2 documentation
- README and screenshot updates
- Version delta documentation between v1.0.0 and v1.1.0

## Activity Page Sections

The Activity page must include:

1. Header: Activity / Daily movement and fitness tracking
2. Time filter: Today / Week / Month
3. Today's Movement hero card
4. Activity Goals card
5. Hourly Movement chart
6. Today's Activity Sessions
7. Intensity Zones
8. Activity Insights

## Out of Scope for Release 2

Release 2 will not include:

- Backend integration
- Database connection
- Authentication
- Real medical data
- API integration
- Real wearable device connection
- Full implementation of all sidebar pages

## Release 2 Principle

Release 2 must build on top of v1.0.0. It must not replace or rewrite the meaning of Release 1.
