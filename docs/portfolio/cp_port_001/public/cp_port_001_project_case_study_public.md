## Project Overview

BinarWell Flutter Dashboard is an inspired wellness dashboard prototype built with Flutter and Dart.

The project began as a polished single-page wellness dashboard and was expanded in version v1.1.0 into an Activity-first multi-page dashboard experience.

The goal of the project is to demonstrate clean Flutter UI structure, reusable dashboard components, responsive layout thinking, mock data separation, documentation-driven development, and GitHub release workflow.

## Problem Statement

Many dashboard prototypes focus only on visual appearance and do not show enough engineering discipline.

This project was created to demonstrate that a portfolio dashboard can include both visual polish and structured software workflow.

The project focuses on:

- Clean file organization
- Reusable UI components
- Mock data separation
- Navigation structure
- Responsive review
- Testing and validation
- Release documentation

## Solution

The solution was to build a Flutter dashboard with a clear Overview page and then expand it into a multi-page structure through Release 2.

Version v1.1.0 introduces a dedicated Activity page with its own page identity, sidebar navigation state, layout structure, visual cards, mock data, responsive review, and widget test coverage.

The project was developed using a micro-gate workflow.

The workflow included:
