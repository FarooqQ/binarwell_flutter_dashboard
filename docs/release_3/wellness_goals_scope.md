# Wellness Goals Scope

## Project

CarePulse Flutter Dashboard

## Target Version

v1.2.0

## Release Name

Release 3 — Wellness Goals Expansion

## Implementation Track

CP-R3-001 — Wellness Goals Page Implementation

## Current Micro-Gate

CP-R3-001-MG1 — Reference Lock and Scope Definition

## Scope Summary

This micro-gate locks the approved visual reference and defines the implementation scope for the Wellness Goals page before writing code.

No Flutter UI code will be changed in this stage.

## In Scope

This release will add a dedicated Wellness Goals page that includes:

- Header with page title and Add Goal button
- Today date filter
- Goal summary KPI cards
- Today’s Goal Checklist
- Goal Focus of the Week
- Weekly Goal Planner
- Goal Categories
- Recent Achievements
- Wellness Insights
- Responsive layout review
- Widget tests
- Documentation and README update
- Final release preparation

## Out of Scope for MG1

The following items are not part of MG1:

- Creating Flutter models
- Creating mock data
- Registering routes
- Updating sidebar navigation
- Building UI widgets
- Updating README
- Running Flutter tests
- Publishing to GitHub

These will be handled in later micro-gates.

## Design Constraints

The Wellness Goals page must:

- Stay visually consistent with CarePulse
- Remain different from the Activity page
- Use clear KPI cards with different meanings
- Reduce unnecessary small text density
- Make the Add Goal button clearly visible
- Support future responsive review
- Be suitable for public GitHub portfolio presentation

## GitHub Publishing Consideration

Release 3 will be published later on the personal GitHub account after the final gate passes.

The release should be documented as a natural continuation of:

- v1.0.0 — Initial polished dashboard release
- v1.1.0 — Activity-first multi-page expansion
- v1.2.0 — Wellness Goals expansion

The previous releases should remain understandable and protected as portfolio milestones.
