# CP-R3-001-MG1 — Reference Lock and Scope Definition

## Document

Wellness Goals Reference Lock

## Project

CarePulse Flutter Dashboard

## Target Version

v1.2.0

## Release

Release 3 — Wellness Goals Expansion

---

## Approved Visual Reference

The approved visual reference for the Wellness Goals page is the selected Wellness Goals design direction prepared before implementation.

The page should feel connected to the existing CarePulse dashboard system, especially the main Overview page and the Activity page, while still having its own clear identity.

---

## Visual Direction

The Wellness Goals page should focus on:

- Personal health goals
- Goal progress
- Active goals
- Completion rate
- Goal categories
- Weekly goal planning
- Encouraging wellness insights
- A clear Add Goal or New Goal action

---

## Design Identity

The page must not look like a duplicate of the Activity page.

The Activity page focuses on movement, sessions, steps, calories, zones, and daily activity behavior.

The Wellness Goals page should focus on planning, target tracking, long-term progress, habits, and personal wellness commitments.

---

## Required Page Sections

The Wellness Goals page should include:

- Page header
- Add Goal / New Goal button
- Goal overview summary
- Goal completion card
- Active goals card
- Completion rate card
- Goal progress list
- Goal categories
- Weekly goal plan
- Wellness insights section

---

## Difference from Activity Page

The Wellness Goals page is not a movement-tracking page.

It should not mainly present activity sessions, hourly movement charts, or intensity zones.

Instead, it should present goal status, target progress, completion behavior, and planning information.
