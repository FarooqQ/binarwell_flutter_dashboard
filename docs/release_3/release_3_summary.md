# BinarWell Flutter Dashboard v1.2.0

## Release 3 — Wellness Goals Expansion

BinarWell Flutter Dashboard v1.2.0 expands the project with a dedicated Wellness Goals page.

The new page focuses on goal tracking, habit consistency, weekly planning, category progress, achievements, and wellness insights.

## Main Addition

Release 3 adds a complete Wellness Goals experience to the existing dashboard system.

The page is designed as a separate section, not as a duplicate of the Activity page.

## Added Sections

- Wellness Goals header
- Today filter
- Add Goal action
- Summary KPI cards
- Today's Goal Checklist
- Goal Focus of the Week
- Weekly Goal Planner
- Goal Categories
- Recent Achievements
- Wellness Insights

## Technical Additions

- Wellness Goals feature folder
